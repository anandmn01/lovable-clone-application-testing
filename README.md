# Lovable Clone Application

This repository contains the Lovable clone application.

## Project Structure

- `frontend/` - Contains the React + Vite frontend application.
- `backend/` - Contains the Spring Boot backend service.

## Getting Started

### Prerequisites

- Node.js (v18+) & npm
- Java 21+ & Maven

### Running Frontend

```bash
cd frontend
npm install
npm run dev
```

### Running Backend

```bash
cd backend
./mvnw spring-boot:run
```
